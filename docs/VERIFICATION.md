# 驗證（0.7.1）

## 自動化

`Test AgentDock.cmd`（或 `uv run pytest -q`），Linux 離屏環境 52 項通過：

- 問答儲存、broker 權限、真實 MCP stdio 往返（ask_user → 回答 → 附件）、逾時不產生答案。
- 設定管理：預覽／備份／失敗復原、Codex TOML 保留註解、Claude 停用移出與還原、舊 QAI 名稱遷移。
- MCP 庫：匯入既有設定、uvx／npx 判斷、本機路徑不進 Git、從 Agent 設定補回本機值、祕密檔加解密與合併。
- 擴充庫：rtk hook／plugin 寫入與移除、更新後自動套用、排序。
- 浮動視窗：兩種模式、縮放記住大小、泡泡回答、全螢幕休息、背景透明度、額度每個視窗都顯示。
- 設定被外部移除的 MCP 會被標出，可補回或忽略。

## Windows 實機檢查清單

測試環境沒有真的 Windows 桌面，以下要在實機確認。有問題的項目記下現象（最好附截圖）回報即可。

### 啟動與常駐

- [ ] 雙擊 `AgentDock.exe` 沒有任何 cmd 視窗；`uv.lock` 有變更時會先出現「AgentDock 準備中」再自動開啟。
- [ ] 系統匣有愛心圖示；點一下切換浮動視窗／小圖示；右鍵可「結束」。
- [ ] Ctrl+Alt+Q 找回浮動視窗。
- [ ] 右鍵勾「開機自動啟動」→ 登出再登入（或重開機）後自動出現；取消勾選後不再出現。

### 浮動視窗

- [ ] 永遠在最上層；開關其他視窗、Win+D 之後仍在。
- [ ] 拖曳標題列移動；拖到螢幕邊緣會貼齊；位置在重開後保留。
- [ ] 四邊與四角都能縮放，有最小尺寸；重開後大小保留。
- [ ] 右鍵「背景透明度」各級：底色變透明，文字、進度條、蝴蝶結維持清楚；重開後保留。
- [ ] 右鍵切換可用外觀；無本機主題檔時僅有預設極簡，Ctrl+Alt+H 同步切換視窗及系統匣圖示。
- [ ] 「–」或 Esc 縮成小愛心；點愛心展開。

### 額度

- [ ] Claude Code、Codex（每個 workspace）、Grok 每個視窗（5H／W）都有進度條與重置倒數。
- [ ] ⟳ 立即更新；小圖示時不更新，展開後若資料過舊會馬上更新。
- [ ] 另外開著的舊 TokenGauge 會被關閉並出現通知。

### 問答（請 Agent 呼叫 ask_user）

- [ ] 浮動視窗開著：自動切到「問答」，答完回到原本那頁；不搶走正在打字的焦點。
- [ ] 小圖示：愛心發光跳動並顯示題數；簡單單選題冒出泡泡，點選項就送出。
- [ ] 小圖示：Windows 通知「<Agent> 有新問題」；點通知會展開並打開那一題；右鍵取消「新問題通知」後不再通知。
- [ ] 全螢幕（遊戲／影片）時自動縮成小圖示且不跳泡泡；離開全螢幕後恢復。

### 設定

- [ ] 手動從某個 Agent 的設定檔刪掉一個 MCP（或讓客戶端更新覆寫）→ 重開「設定」頁：該 MCP 標示「被移除了」、卡片的「設定」分頁有 •；「補回」後套用即恢復；按 × 不再提醒。
- [ ] MCP 庫 ⋯ →「匯出祕密」設定密碼產生 `.adsecrets`；另一台電腦「匯入祕密」：缺的補上，本機已有的值（例如不同的路徑）保留。
- [ ] mcp-google-sheets：pull 後 `mcp-library.json` 不再含本機路徑；這台電腦的路徑自動從 Agent 設定補回，各 Agent 不顯示「需更新」。
- [ ] rtk：hook 實際觸發（Claude Code／Codex 執行 shell 指令時被改寫）、「加入 PATH」後新開的終端機找得到 rtk。
