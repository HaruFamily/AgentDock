# AgentDock 設定交易

以倉庫根目錄讀 AGENTS.md、docs/ARCHITECTURE.md 的設定管理段，以及任務涉及的 agents.py、library.py、extensions.py。先以圖譜定位再讀交易方法，不假設每個模組各自寫檔。

- 先產出可檢查的預覽，使用者確認後才備份與套用真實客戶端設定。此規則不要求每次改本機專案圖示／側欄寬度都跳確認。
- 同檔多來源更新應組成一次交易，避免 MCP 與擴充覆蓋彼此。套用前重查檔案內容、Agent 註冊與執行檔依賴；外部修改需重新預覽。
- 保留使用者未管理欄位與本機祕密。路徑／token 不寫入公開範本、日誌或 Git；使用既有佔位符與 secrets 分離機制。
- 批次失敗恢復整批，備份應能辨識原檔及時間；不能只恢復最後一檔。不要自行執行上游 install/update 來重寫整份設定。
- 「存在」「同步」「客戶端已載入」是不同證據層級，UI 與報告不可混用。取消與逾時不能套用。

用暫存目錄測：初次套用、已同步、外部修改衝突、缺依賴、半途寫入失敗回復、秘密分離、保留未知欄位。同一份 config 的多項變更要一起驗證。不得用真實客戶端設定驗證寫入。
