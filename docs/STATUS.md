# 現況：0.5.0

更新日期：2026-10-01。

## 已實作

- Windows 免安裝平台、系統匣、置頂及共用視窗。
- 選配 QAI：文字／附圖提問、單選／多選／自由文字、選項備註、回答附件、草稿與歷史。
- 多個 MCP caller 獨立等待，取消及逾時不會產生默認同意；可恢復等待。
- 記住 Agent 設定檔，預覽／備份／批次寫入、MCP 啟停。
- QAI .admod 本機匯入與 HTTPS 下載；QAI ZIP 獨立發行及平台依賴補齊。
- 正式倉庫結構、docs 與開發 Skill；開發資料集中在 .local，舊 .ail/archive 不再保留。

## 驗證邊界

自動化驗證涵蓋設定保存與還原、套件驗證、SDK stdio 問答、桌面互動、免安裝包與冷啟動。
測試只使用隔離資料；沒有替使用者實際安裝到個人 Agent 設定。
四種客戶端設定格式已測試，但各真實 App／Provider 的授權、繼承設定及逾時仍須實機確認。
問答附件不自動解析 PDF／Office，交由接收端能力處理。

## 未完成
